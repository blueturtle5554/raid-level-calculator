Calculation assumptions

Both players start with zero unspent souls and receive the same clan raid rewards. They buy level upgrades as soon as they can afford them.

The strongest player determines the raid level. One bonus raid is purchased each day, so daily souls = 200 × raid level.

Upgrade cost = 150(3L² + L). Maximum beatable raid = 3L − 4 for player level 2 and above.

This finds the first day the players reach the same level, not when they have exactly the same unspent souls.
